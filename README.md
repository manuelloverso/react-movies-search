# Have you watched it?

Here is the live version --> https://haveyouwatchedit.nelify.com

### Description

A web app where you can search movies through a searchbar, watch details like genres, runtime, vote average and more. You can then vote the movie and add it to the watched list that will survive on refresh and stay persistent.

### Tech Stack

- HTML, CSS, JS
- React
- Tailwind
- Vite
